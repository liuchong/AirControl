# AirControl v1 当前计划

状态：双手辅助状态机、Vision 自动恢复、摄像头重启恢复、新品牌、右手过程性抓窗和普通摄像头九点视线辅助已经实现并通过统一验证，固定签名版本已安装并从 `/Applications/AirControl.app` 启动。当前只等待用户在真实光照、眼镜和摄像头条件下验收粗定位精度。

核心结果：右手或未知单手提供普通光标、左右键、拖拽和滚动；明确左手提供精细稳定、光标锁定、双击、辅助滚动、辅助拖拽和暂停。明确右手稳定张掌后在 0.65 秒内完成收拢并连续两帧握拳，可以抓取当前光标下的可移动窗口。可选视线辅助默认关闭，九点校准后在无手时粗定位，右手从视线落点无跳动相对接管；闭眼、丢脸和低置信度冻结且永不点击。平台无关业务规则只在 Rust 实现，Swift 只提供 Vision 原始检测与 macOS 系统执行，供未来 Windows/Linux 外壳复用。

直接阻塞项：自动化、本机安装与启动范围内无已知阻塞项。真实抓窗手势、不可移动系统窗口的软失败体验和显示器热插拔仍需用户验收，边界与步骤记录在 `docs/testing.md`。

范围外改进：全身姿态、多人识别、键盘控制、自定义模型、App Store 发布；左手横扫切换显示器与指间距速度拨盘仅保留产品设想，没有入口和半成品代码。

验证：Rust 格式、静态分析和 55 条测试通过；Swift/macOS 单元与真实 Rust 静态库跨语言集成测试合计 36 条通过；统一验证通过。视线链路覆盖九点稳定采样、坏校准拒绝、闭眼/丢脸/低置信度冻结、屏幕映射、视线到右手无跳动接管和损坏持久数据降级。过程性抓窗覆盖孤立拳头、完整动作、锚点冻结、握拳防跳、超时/反向取消、左手冲突、丢手/停止释放、输出缓冲区事务重试和 ABI 第 4 版命令序列。已安装应用通过严格签名校验，应用标识与本机固定签名身份一致，进程从 `/Applications/AirControl.app` 运行。
