# AirControl v1 当前计划

状态：双手辅助状态机、Vision 自动恢复、摄像头重启恢复、新品牌、右手过程性抓窗、普通摄像头九点视线辅助、校准后自动恢复控制和屏幕辅助光源已经实现并通过统一验证。辅助光源关闭状态绕过问题已修复，固定签名版本已覆盖安装并从 `/Applications/AirControl.app` 启动；当前等待用户在真实光照、眼镜、摄像头和九点校准条件下验收。

核心结果：右手或未知单手提供普通光标、左右键、拖拽和滚动；明确左手提供精细稳定、光标锁定、双击、辅助滚动、辅助拖拽和暂停。明确右手稳定张掌后在 0.65 秒内完成收拢并连续两帧握拳，可以抓取当前光标下的可移动窗口。可选视线辅助默认关闭，九点校准后在无手时粗定位，右手从视线落点无跳动相对接管；闭眼、丢脸和低置信度冻结且永不点击。控制中校准成功会在权限仍有效时复用摄像头重连路径自动恢复，取消、失败和权限变化不误启动。屏幕辅助光源默认关闭，可调亮度与冷暖色并独立持久化，不抢鼠标键盘焦点。平台无关业务规则只在 Rust 实现；柔光窗口和设置属于 macOS 平台外壳，不建立无意义的薄共享层。

直接阻塞项：自动化、本机安装与启动范围内无已知阻塞项。真实抓窗手势、不可移动系统窗口的软失败体验和显示器热插拔仍需用户验收，边界与步骤记录在 `docs/testing.md`。

范围外改进：全身姿态、多人识别、键盘控制、自定义模型、App Store 发布；左手横扫切换显示器与指间距速度拨盘仅保留产品设想，没有入口和半成品代码。

验证：Rust 格式、静态分析和 55 条测试通过；Swift/macOS 单元与真实 Rust 静态库跨语言集成测试合计 45 条通过；统一验证通过。新增覆盖校准恢复意图的一次性消费、取消/失败/权限边界，以及柔光默认值、损坏数据回退、跨存储重载和关闭状态在校准刷新中的强制保持。视线链路继续覆盖九点稳定采样、坏校准拒绝、闭眼/丢脸/低置信度冻结、屏幕映射和无跳动接管。安装后的应用已通过严格签名校验，辅助光源持久化开关为关闭，进程从 `/Applications/AirControl.app` 启动。
