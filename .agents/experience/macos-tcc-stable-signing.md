# macOS 权限与本地稳定签名

macOS 隐私权限识别的是应用代码身份，不只是应用路径和 `CFBundleIdentifier`。临时签名默认产生只绑定当前代码哈希的指定要求，重建后哈希变化，摄像头、辅助功能和屏幕录制等授权可能无法继承。

本机开发可使用长期保存在登录钥匙串中的自签名代码签名身份。每次构建必须使用同一证书和同一应用标识，并检查 `codesign -d -r-` 输出：不同二进制的指定要求应相同，且不应只包含 `cdhash`。

签名工具在身份缺失时必须失败关闭，不能静默回退到 `codesign --sign -`。首次从临时签名迁移到固定签名仍可能需要用户重新授权一次。仅切换旧辅助功能行的开关可能继续操作旧代码身份：如果系统设置显示开启但 `AXIsProcessTrusted()` 仍返回 false，应移除旧行，再通过“添加”明确选择当前 `/Applications/AirControl.app`。验证是否真正解决问题必须在这个新记录生效后，再执行一次不同构建的覆盖安装和应用重启。

沙箱中的 `security find-identity` 可能看不到用户登录钥匙串并错误显示零个身份。诊断时应在用户允许后于沙箱外复核；不能据此删除证书、重复创建身份或改回临时签名。
